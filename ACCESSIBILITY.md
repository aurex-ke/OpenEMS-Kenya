# Accessibility

This document describes accessibility practices for the materials in this
repository: research and planning documents, reports, spreadsheets, images, and
other project resources. It is not a statement that every file has been
formally audited or meets a particular accessibility standard.

The programme's [Stakeholder Engagement Plan](docs/Stakeholder_Engagement_Plan.md)
commits to inclusive engagement and materials in plain language, in English
and Kiswahili where relevant, and in formats suited to the audience. This file
applies that commitment to the repository.

## Practices for repository materials

- **Use clear structure and language.** Organize documents with descriptive
  headings in order, write in plain language, explain technical terms and
  acronyms, and use descriptive link text.
- **Make visual information understandable without sight or colour
  perception.** Add useful alternative text to images and charts. Explain
  important trends and conclusions in text, and do not use colour alone to
  communicate meaning.
- **Keep tables and spreadsheets navigable.** Use simple tables with clear
  column headings. In spreadsheets, label rows and columns, include units, and
  do not rely on colour alone to identify values or status.
- **Check exported documents.** Where a Word, Excel, or PDF version is
  provided, preserve headings and reading order, use labelled table headers,
  and ensure text can be selected and read by assistive technology. Provide a
  source or alternative format where practical.
- **Consider audience and access needs.** Use English and Kiswahili where
  relevant, and choose formats suited to the people who will use the material.
  When preparing engagement materials, consider accessible digital and
  non-digital ways to receive the information.

## Known limitations

Repository materials are maintained in different formats and may not yet be
usable by everyone. Accessibility can vary between a source file and its
exported version, and the project has not established that all materials have
been tested with assistive technologies. We will address identified barriers
as materials are updated; no claim of formal conformance is made here.

## Report an accessibility barrier

If a repository file is difficult to access or use, please open an issue or
contact the maintainers as described in [CONTRIBUTING.md](CONTRIBUTING.md).
Please identify the file and describe the barrier and, if possible, what
alternative would help. Do not include personal or sensitive information in a
public issue.
